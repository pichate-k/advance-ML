# Lab 08: Text Mining and Sentiment Classification

## ไฟล์ในโฟลเดอร์

- `01_text_mining_lab_student.ipynb`
  - ไฟล์ Notebook สำหรับทำแลปและส่งงาน

- `customer_feedback_sentiment.csv`
  - ชุดข้อมูลข้อความภาษาไทยสำหรับ sentiment classification

## วิธีเริ่มทำงาน

1. เปิด `01_text_mining_lab_student.ipynb` ด้วย Google Colab
2. เลือกเมนู `File > Save a copy in Drive`
3. เปลี่ยนชื่อไฟล์เป็น:
   `student_id_text_mining_lab.ipynb`
4. ดาวน์โหลดไฟล์ `customer_feedback_sentiment.csv` ลงเครื่อง
5. รัน cell สำหรับ Upload Dataset
6. เลือกไฟล์ `customer_feedback_sentiment.csv`
7. ทำส่วนที่มีป้าย `TODO` และ `ANALYSIS`
8. ตรวจว่า Notebook รันได้จากบนลงล่างก่อนส่ง
